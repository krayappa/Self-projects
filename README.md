# Self-projects

## Digital Name Card

This repository now includes a ready-to-publish digital name card page in `index.html`.

### Publish on GitHub Pages

1. Push this branch and merge it to `main`.
2. In GitHub, open the repository settings.
3. Go to `Pages`.
4. Set source to `Deploy from a branch`.
5. Select branch `main` and folder `/ (root)`.
6. Save.

Your page URL will be:

`https://krayappa.github.io/Self-projects/`

After the site is live, the built-in QR card on the page will automatically point to the final page URL.
