# Self-projects

A collection of self-initiated front-end projects.

## User Profile Settings Page

A clean, responsive **User Profile Settings** page built with plain HTML, CSS, and JavaScript — no frameworks required.

### Features

- **Avatar upload** – upload a photo or fall back to auto-generated initials
- **Profile form** – first/last name, email, username, bio, and timezone selector
- **Notification toggles** – email notifications, marketing emails, and two-factor authentication
- **Live feedback** – toast notification on save
- **Responsive layout** – works on desktop and mobile

### Usage

Open `index.html` directly in any modern browser — no build step needed.
